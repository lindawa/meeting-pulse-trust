# Security Policy

## Report Privately

Use [GitHub private vulnerability reporting](https://github.com/lindawa/meeting-pulse-trust/security/advisories/new)
to report suspected security issues confidentially to the repository maintainers.
Do not file a public issue or pull request with vulnerability details, credentials,
meeting content, participant information or other sensitive data.

If private reporting is unavailable, contact the maintainer through an established
private channel. Do not post the report publicly as a fallback.

Provide a high-level description, the affected documentation page or asset, and
minimal, redacted reproduction steps. Use synthetic examples rather than real
meeting data. Do not upload private documents or include secrets.

## Scope

This repository contains only the public documentation site and its build tools.
The current `main` branch is maintained; archived revisions are not separately
supported. Documentation statements are not a substitute for an application's
security policy or a guarantee of legal or compliance approval.

For ordinary questions, use the site's support page. Security-sensitive concerns
should stay in the private reporting channel above.
